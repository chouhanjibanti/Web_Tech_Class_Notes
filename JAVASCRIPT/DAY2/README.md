Datatype :- which type of value we are storing.

var a = 10;

we have two type of DT:- 
1. primitive:- predefined and inbuilt
2. non  primitive DT :- userdefined DT 


Primitive DT :- 
1. Number 
2. String 
3. boolean 
4. null 
5. undefined 
6. bigint

===========================================


Typecasting :- by using this we can convert one datatype to another datatype.

1. implicit Typecasting :- it the automatically converted one dt to another dt.
2. Explicit Typecasting :- converting the dt explicitly/mannual from  one dt to another dt.
