Datatype :- which type of value we are storing .

type of DT :
1. primitive DT :- predefined DT & inbuilt DT -> we can not change this.
2. Non primitive DT :- userDefined DT -> we can change easily.

Primitive DT :- 
1. Number 
2. String 
3. Boolean
4. null 
5. undefined 
6. Bigint 

Non primitive DT :- 
1. Array
2. Object 
3. Functions 

=====================

Typecasting  :- convert one datatype to another datatype.

in JS we have two types of Typecasting 
1. Implicit typecasting :- it automatically convert one to another dt.
   
2. Explicit Typecasting  :- it manual /externaly convert one to another dt.
