Loops :- we perform the repeatative task./ iteration.


type of loop .
1. for loop
2. while loop
3. do-while loop

Diff b/w for loop and while loop.
1. number of iterations known
2. in while loop number of iteration is known.

1. in for loop all things like init , condition , incre/decr in single line.
2. in while loop like init , condition , incre/decre in diff diff line.

1. for loop Syntax :- 
   for(init;condition;incre/decre){
      // code to execute
   }

2. Syntax of while loop
   init
   while(condition){
    incre/decre;
   }

Diff between while loop and do-while loop

1. while loop entry control loop.
2. do-while loop is exit control loop.

1. while it wil execute based on the condition.
2. do-while at least one time run ,then it will check the condition.

1. Syntax of while 
 init
   while(condition){
    incre/decre;
   }

2. do-while loop
   init
   do{
    // code to execute 
   }while(condition)
